API

Everything the studio does is available over REST. Requests are asynchronous: you start a generation, then poll it until it's done. Usage is billed from your account's credits at the same rates as the studio.

Authentication

Create a key under Account → API keys and send it as a bearer token. Keys are shown once; revoke any key you think has leaked.

Authorization: Bearer c3d_live_…
GET/v1/account

Returns your email, credit balance and current prices.

Image → 3D model

POST/v1/models/upload

Multipart upload. Fields: file (PNG, JPG or WEBP, up to 15 MB) and the options below.

POST/v1/models

JSON body with exactly one image source: image_url (public https), image_base64, or image_generation_id from /v1/images.

OptionDefaultValues
resolution1024512 (fast), 1024, 1536 (highest). Sets the credit cost.
decimation_target300000Target polygon count, 20,000 to 1,000,000
texture_size20481024, 2048 or 4096
seedrandomInteger, for reproducible results

Backgrounds are removed automatically. For best results send one object, fully in frame.

Idea → image

POST/v1/images
{ "prompt": "a brass steampunk owl", "style": "stylized", "optimize_for_3d": true }

Styles: realistic, stylized, cartoon, lowpoly, clay, figurine. With optimize_for_3d the image is steered toward a single, centred object on a clean background. Pass the finished id to /v1/models as image_generation_id.

Get a result

GET/v1/generations/{id}

Poll every 2–5 seconds. status moves from queued to running to done or failed. When done, output.glb_url (or output.image_url) is a signed link valid for an hour; fetch the generation again for a fresh link.

{
  "id": "5f0c…", "kind": "model", "status": "done", "progress": 100,
  "cost_credits": 10,
  "output": { "glb_url": "https://…", "download_url": "https://…", "size_mb": 7.4 }
}

Credits and errors

Credits are deducted when a generation starts and returned automatically if it fails (refunded: true). Errors return JSON with a detail message.

StatusMeaning
400Invalid input, for example an unreadable image or bad option
401Missing, invalid or revoked API key
402Not enough credits. Buy more
429Too many requests (60 per minute) or too many generations running at once

Full example (Python)

import time, requests
API = "{{APP_URL}}"
H = {"Authorization": "Bearer c3d_live_…"}

with open("chair.png", "rb") as f:
    gen = requests.post(f"{API}/v1/models/upload", headers=H,
                        files={"file": f}, data={"resolution": "1024"}).json()

while gen["status"] in ("queued", "running"):
    time.sleep(3)
    gen = requests.get(f"{API}/v1/generations/{gen['id']}", headers=H).json()

if gen["status"] == "done":
    open("chair.glb", "wb").write(requests.get(gen["output"]["glb_url"]).content)
else:
    print("Failed:", gen["error"])
